
# SQL More Queries

This directory contains SQL exercises and projects covering advanced query techniques.

## Topics Covered
- JOINs (INNER, LEFT, RIGHT, FULL)
- Subqueries
- Aggregation functions
- GROUP BY and HAVING clauses
- Set operations (UNION, INTERSECT, EXCEPT)
- Window functions
- Common Table Expressions (CTEs)

## Files
- `*.sql` - SQL query files with solutions

## Usage
Execute SQL files against your database:
```sql
source filename.sql;
```
