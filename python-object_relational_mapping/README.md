# Python Object-Relational Mapping

## Overview
This project explores **Object-Relational Mapping (ORM)** in Python, focusing on database interaction patterns and best practices.

## Topics Covered
- SQLAlchemy basics
- Model definition and relationships
- Database queries and filtering
- Session management
- Migrations and schema updates

## Requirements
- Python 3.x
- SQLAlchemy
- Database (PostgreSQL/MySQL/SQLite)

## Usage
```bash
python main.py
```
