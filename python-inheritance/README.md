
# Python Inheritance

This directory contains Python exercises focused on object-oriented programming and inheritance concepts.

## Topics Covered

- Class definition and instantiation
- Inheritance and method overriding
- Super() function
- Multiple inheritance
- Polymorphism

## Files

Each file demonstrates specific inheritance patterns and concepts through practical examples.

## Usage

Run individual Python files to see inheritance in action:

```bash
python3 filename.py
```
